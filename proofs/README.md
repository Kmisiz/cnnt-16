# proofs

Bằng chứng kiểm thử, chia theo bài test.

| Thư mục | Nội dung |
|---|---|
| `KT1/`, `KT2/`, `KT3/` | Ảnh và log của các bài kiểm thử nghiệm thu |
| `SIEM/` | Ảnh dashboard Wazuh cho các kịch bản giám sát |
| `raw/` | Log và dữ liệu thô |

Quy tắc: ảnh phải thấy thời gian, tên file có timestamp dạng `ten-bai_YYYY-MM-DDTHH-MM-SS.png`, che mật khẩu, khóa và token trước khi lưu.
